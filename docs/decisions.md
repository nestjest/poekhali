## Этап 10: сервер урока на Vercel (2026-10-26)

| № | Решение | Почему |
|---|---|---|
| 82 | Vercel: игра — статика (`frontend/dist`), сервер урока — serverless-функция `api/index.py` (тот же FastAPI), `vercel.json` переписывает `/api/*` | Пользователь: «нужно, чтобы с бэкендом было на Vercel» |
| 83 | База на Vercel — PostgreSQL (`DATABASE_URL`, Neon из Marketplace); `store.py` один и тот же SQL для SQLite и PostgreSQL (`?` → `%s`, `ON CONFLICT … DO UPDATE`, `RETURNING id`), драйвер psycopg 3 подключается только для URL; в классе по-прежнему SQLite без внешних сервисов | У serverless нет постоянного диска; локальный запуск не должен требовать СУБД |
| 84 | Без WebSocket (Vercel их не держит): ученик и пульт опрашивают сервер каждые 3 с, после 3 неудачных попыток WebSocket больше не пробуют; при живом сокете опрос раз в 15–20 с. API отвечает `Cache-Control: no-store`, клиент — `cache: 'no-store'` | Урок не должен ждать 20 с после «Открыть этап»; CDN и браузер не кэшируют состояние |
| 85 | Пароль преподавателя на Vercel — `BUREAU_TEACHER_PASSWORD`; при каждом холодном старте `ensure_password` перезаписывает его только при изменении (токены преподавателя не сбрасываются) | Serverless-функция стартует много раз за урок |
| 86 | На Vercel нет `checker`: `/api/check` → 503, программы проверяет браузер ученика (как без Docker) | Правило «сервер урока код не выполняет» сохраняется |

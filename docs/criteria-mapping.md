# Соответствие критериям конкурса

Ресурс: образовательная игра-курс «Поехали!» (Python для СПО, действие — в вымышленном Бюро «Космос») для конкурса «Лучший цифровой образовательный контент нового поколения в рамках освоения МДК/модуля». Критерии взяты из `PROMPT.md`, раздел 0.

Эксперту не нужно ничего устанавливать: ресурс открывается по ссылке в браузере, без VPN, шрифты, графика и Pyodide лежат на том же сервере (без CDN). Адреса ниже даны относительно корня сайта (при локальном запуске — `http://<адрес>:8000/`).

## Как быстро посмотреть (3 минуты)

1. `/` → «Самостоятельно» — вход без сервера и пароля, этапы открываются по мере прохождения.
2. `/#/experts` — страница для экспертов: краткий маршрут по ресурсу и ссылки на всё ниже.
3. `/#/teacher` — пульт урока (нужен запущенный сервер урока и пароль преподавателя, см. `docs/teacher-guide.md`).
4. `/#/plan/0` … `/#/plan/3` — планы уроков; `/#/print/0` … `/#/print/3` — печатные материалы.

## Карта экранов и адресов

| Адрес / экран | Что это | Для кого |
|---|---|---|
| `/` | Игра. Титул: «Продолжить», «Войти в урок» (код урока + псевдоним), «Самостоятельно», «Настройки» | студент, эксперт |
| `/#/teacher` | «Пульт урока»: этапы, задания, «Внимание!», сообщения, живая панель класса, частые ошибки, зачёт, отчёт CSV | преподаватель |
| `/#/present` | Проектор: код урока, текущий этап, сколько учеников сдали каждое задание (без псевдонимов), «Внимание!», опрос с диаграммой ответов | преподаватель |
| `/#/experts` | Страница для экспертов: паспорт ресурса, маршрут на 3 минуты, критерии → где посмотреть, запуск в режимах «Игра», «Классика», «Знакомство» | эксперт |
| `/#/plan/0` … `/#/plan/3` | План занятия 0–3: цель, ПК/ОК, этапы с минутами, подсказки, рефлексия, домашнее задание; печать | преподаватель, методист |
| `/#/print/0` … `/#/print/4` | Печатные материалы занятия: конспект ученика, лист рефлексии, критерии и рубрика; каждый лист с новой страницы, «Печать / PDF» | преподаватель, студент |
| `/#/art` | Галерея собственной графики (персонажи × 5 эмоций, локации, предметы) | эксперт |
| `/#/checks` | Галерея всех 8 типов интерактивных проверок | эксперт, методист |
| `/#/style` | Пробник стиля графики v2 | разработчик, эксперт |
| Настройки (шестерёнка на титуле / в телефоне) | Тема, A−/A+, «читаемый шрифт», режим «Классика» | студент |
| Титул → режим «Знакомство» | Сокращённый маршрут занятий 0–1 для школьников (профориентация) | школьник |

Режимы «Классика» и «Знакомство» выбираются в настройках и на титуле; служебные страницы с адресом `/#/…` — не часть игры.

## Видео (до 7 минут)

План съёмки по шагам — `docs/approbation-guide.md`, раздел «Видео до 7 минут». Видео показывает путь: титул → вход по коду → пульт открывает этап → задание ①–④ → замечание заказчика → доработка → запуск аппарата → панель класса и отчёт.

## Что в ресурсе пока ограничено (честно)

- Прогресс студента хранится в его браузере; на сервер уходит только сводка.
- Скрытые кейсы есть и в клиентском бандле (браузер проверяет без сервера). Серверная проверка (Docker-checker) засчитывает результат по кейсам с сервера, но включается только при развёртывании через `docker compose`; при запуске `python -m bureau_server` проверяет браузер.
- Показатели апробации и юзабилити не заполнены, пока не проведено тестирование.

# «Поехали!» — руководство преподавателя

Курс Python с нуля для СПО (МДК 05.04, тема 5.4.1). Ученики работают в игре в вымышленном Бюро «Космос». Вы ведёте урок с **«Пульта урока»**: открываете этапы, следите за классом, помогаете, проводите опросы. В режиме «Вместе» ученик не пройдёт дальше этапа, который вы не открыли.

Нужен только компьютер преподавателя и локальная сеть класса. Интернет не обязателен. Программист не нужен.

Памятка для учеников — [student-guide.md](student-guide.md). Её можно распечатать или раздать ссылкой.

---

## Шпаргалка на один урок

1. Запустить сервер урока (раздел 2) и открыть пульт `…/#/teacher`.
2. «Новый урок» → занятие, группа, режим «Вместе» → **код урока** на проектор («Код на весь экран» или «Проектор ↗»).
3. Ученики: адрес → «Войти в урок» → код + псевдоним.
4. Главная кнопка пульта **«Открыть этап «…»»** — по ходу урока, этап за этапом.
5. Следить за панелью класса: 🔔 «Зовёт», ! «Застрял». Помогать: «Код», комментарий, «Зачесть задание…».
5½. «Конец смены» — командный: при его открытии пульт сам делит класс на экипажи по 2–3 человека (блок «Экипажи и гонка»). Разбейте раньше — гонка экипажей пойдёт весь урок.
6. В конце: **«Отчёт урока (CSV)»** → «Завершить урок…».

## 1. Установка (один раз)

### Вариант А — обычный (Python)

Нужны Node.js 20+ и Python 3.11+.

```bash
cd frontend
npm install
npm run build          # собрать игру
cd ../server
python -m pip install -r requirements.txt
```

Программы учеников проверяются в их браузерах.

### Вариант Б — Docker (с серверной проверкой кода)

```bash
BUREAU_TEACHER_PASSWORD=придумайте-пароль docker compose up --build
```

Поднимаются игра с сервером урока (порт 8000) и отдельный изолированный сервис проверки. Внутри контейнера сервер не знает адрес вашего компьютера в сети, поэтому пишет «Ученикам: http://<адрес этого компьютера в сети>:8000/». Узнайте адрес командой `ipconfig` (Windows, строка IPv4) и продиктуйте его, или задайте его заранее: `BUREAU_PUBLIC_URL=http://192.168.1.10:8000 docker compose up` — тогда его покажут и окно запуска, и пульт, и проектор. Пульт открывайте у себя как `http://localhost:8000/#/teacher`. Он проверяет программы учеников по скрытым испытаниям, которые хранятся на сервере, без доступа в сеть. Результат нельзя подделать в браузере. У ученика под кнопкой появляется «✓ проверено сервером урока», в отчёте — столбец «Проверено сервером».

## 2. Перед уроком

```bash
cd server
python -m bureau_server
```

В окне появится:

```
  «Поехали!» — сервер урока
    Ученикам:        http://192.168.1.20:8000/
    Преподавателю:   http://192.168.1.20:8000/#/teacher

    Пароль преподавателя: vostok-4821-zarya
```

- Пароль показывается **только при первом запуске** — запишите его. Свой пароль: `python -m bureau_server --set-password`, новый случайный: `--reset-password`.
- **Окно не закрывайте** до конца урока. Данные уроков хранятся в файле `server/data/bureau.db` и переживают перезапуск.
- Если ученики не открывают адрес, разрешите Python в брандмауэре Windows (частная сеть). Адрес нужен именно тот, что в строке «Ученикам», а не `localhost`.
- Другой порт: `python -m bureau_server --port 8080`.

**Проверьте заранее** (5 минут):

- Откройте адрес для учеников на одном компьютере класса. Первая загрузка Python в браузере дольше обычной: идёт «Загрузка Python…».
- Посмотрите план занятия: `…/#/plan/N` (кнопка «План урока» на пульте). Там цель, компетенции, этапы с минутами, что сказать, вопросы классу, типичные ошибки.
- Распечатайте материалы, если нужны: на странице плана — «Материалы для учеников» (`…/#/print/N`). Там конспект, лист рефлексии, критерии и рубрика с заданиями занятия. Каждый лист печатается с новой страницы, можно «Сохранить как PDF».

## 3. Начало урока

1. Откройте `…/#/teacher` и войдите по паролю. Вход действует 12 часов.
2. **«Новый урок»**: выберите занятие, впишите группу (необязательно) и режим:
   - **Вместе с классом** (по умолчанию) — этапы открываете вы. Ученик у закрытого этапа видит «Ждём команду ЦУП».
   - **Свободный темп** — все этапы доступны, вы наблюдаете. Режим можно переключить в любой момент.
3. Получите **код урока**, например **КЕДР-42**. Покажите его: «Код на весь экран» или «Проектор ↗».
4. Ученики открывают адрес, нажимают «Войти в урок», вводят код и **псевдоним**. Код можно набрать как угодно: «кедр 42», «KEDR-42», в английской раскладке — всё примется. ФИО не нужны и не собираются.

> Ученик пересел за другой компьютер — пусть войдёт с тем же псевдонимом. На пульте он останется тем же учеником. Игровой прогресс хранится в браузере прежнего компьютера, поэтому сделанные задания засчитайте ему вручную («Зачесть задание…»).

## 4. Ход урока

Главная кнопка пульта — **«Открыть этап «…»»**. Она открывает следующий этап. Открытие этапа открывает и все предыдущие, закрытие — все последующие. У каждого этапа есть «Подсказки к этапу»: что сказать, вопросы классу, типичные ошибки, что делать, если застряли. Под этапом показано, сколько учеников на нём сейчас.

## 5. Инструменты пульта

| Инструмент | Что делает |
|---|---|
| **«Внимание!»** | Затемняет экраны всех учеников и показывает ваше сообщение (есть готовые фразы). Ввод в игре блокируется, пока вы не снимете. На проекторе сообщение крупно |
| **Сообщение классу** | Приходит уведомлением и письмом в пневмопочту, работу не прерывает |
| **Задания** | Любое задание можно закрыть для всех (например, итоговое — до разбора). У учеников оно помечено «Закрыто преподавателем». Видно, сколько учеников его приняли |
| **Опрос класса** | Вопрос и 2–6 вариантов. Есть шаблоны («Как идёт задание?», «Готовы идти дальше?») и вопросы из подсказок к этапу. У учеников по центру экрана появляется панель, ответ можно менять, пока опрос открыт. Ответы **анонимны**: вы и проектор видите только итог. «Закрыть приём ответов» — ученики видят проценты. «Убрать опрос» — панель исчезнет |
| **Проектор ↗** | Открывает `/#/present` в новой вкладке. Перетащите её на проектор и нажмите F11. Там код урока, текущий этап, сколько учеников сдали каждое задание (без псевдонимов), опрос с диаграммой, «Внимание!» |
| **Зовут** | Очередь учеников, нажавших 🔔 «Позвать», по времени вызова. Нажмите «Подошёл», когда помогли |
| **Частые ошибки класса** | Что чаще всего ломается у группы (например «Забыт int() после input()») — повод для разбора у доски |
| **Экипажи и гонка** | Разбить класс на экипажи (2, 3 или 4 человека), переставить ученика, «Зачесть программу (3★)» застрявшему экипажу, прочитать чат экипажа. Табло гонки — здесь и на проекторе |
| **Отчёт урока (CSV)** | См. раздел 8 |

### Конец смены: командная программа и гонка экипажей

**Зачем.** Последний этап каждого занятия 0–3 — работа в команде (ОК 04): экипаж из 2–3 человек собирает одну бортовую программу из частей. У каждого своя часть: **Оператор** (ввод), **Баллистик** или **Аналитик** (расчёт, условия), **Связист** (доклад). Части работают только вместе: Связист печатает переменные, которые создали другие, поэтому экипажу приходится договориться об именах переменных и точных фразах.

**Как идёт.**
1. Вы открываете этап «Конец смены» — пульт сам делит класс на экипажи (сначала те, кто в сети). Позывные экипажей — «Кедр», «Чайка», «Беркут»…
2. У ученика — экран экипажа: своя часть с заданием («Получаешь… / Передаёшь дальше…»), вся программа экипажа (части товарищей видны сразу, по мере набора), чат с быстрыми фразами, табло гонки.
3. Любой член экипажа жмёт «Испытать программу экипажа». Ошибка показывается с указанием части и автора («Ищите в части «Баллистик (Луна)»»).
4. От 3★ экипаж уходит на старт — все его участники продолжают сцену запуска.
5. Застрявшему экипажу можно «Зачесть программу (3★)».

**Музейный опрос.** На экране экипажа есть кнопка «🏛 Музейный опрос»: 4 вопроса по экспонатам «Музея бюро», открытым к концу смены. Один ответ на экипаж (первый нажатый — окончательный), поэтому экипаж обсуждает ответ в чате. Ответ проверяет сервер.

**Гонка экипажей.** Очки экипажа = средние ★ его участников за задания дня + ★ командной программы × 5 + 2 очка за каждый верный ответ музейного опроса + бонус за старт (первый экипаж +10, второй +6, третий +3). Среднее, а не сумма — чтобы экипаж из двух человек не проигрывал экипажу из трёх. Места есть только у экипажей: личного рейтинга нет, никого не выделяем. Разбейте класс на экипажи в начале урока — и табло на проекторе подогревает интерес весь урок.

**Без сервера** (дома, «Самостоятельно») ученик собирает все три части сам — роли подписаны, табло нет.

### Панель класса

Карточка каждого ученика: статус, этап, доля верных ответов, квадратики по заданиям (✓ — принято, цифра — число попыток, · — не начато).

| Статус | Значит |
|---|---|
| 🔔 Зовёт | Нажал «Позвать преподавателя» |
| ! Застрял | 3 и больше проверок текущего задания без принятия или 5 минут без действий |
| ⏸ Ждёт этап | Дошёл до закрытого этапа |
| ▶ В работе | Работает |
| ✓ Сдал итог | Итоговое задание принято (или зачтено вами) |
| ○ Не в сети | Вкладка закрыта или нет связи |

Фильтр над панелью показывает только нужную группу, например «Застрял».

## 6. Как помочь ученику

1. **Посмотрите код**: кнопка **«Код»** на карточке. Там последняя версия программы по каждому заданию (только чтение, обновляется сама, пока окно открыто) и результат серверной проверки, если она включена.
2. **Напишите комментарий** там же. Он придёт уведомлением и письмом в пневмопочту. Есть готовые фразы («Проверь кавычки и скобки», «Сравни вывод с примером в ТЗ», «Подойду через минуту»). **Не пишите готовое решение**: курс построен на том, что ученик находит ошибку сам.
3. **Посоветуйте ученику**:
   - прочитать сообщение об ошибке под редактором (Вика переводит его: что случилось → где → что проверить);
   - нажать «Пошагово»;
   - взять подсказку;
   - спуститься на ступень ниже: «Заполнить пропуски» или «Собрать из строк».
4. **«Зачесть задание…»** — если ученик застрял надолго, сделал задание на бумаге или в Thonny или пересел за другой компьютер. Задание засчитывается как 3 ★ и открывает путь дальше. В отчёте видно, что зачтено вами.

## 7. Оценивание

Игровая премия и «надёжность бюро» **на оценку не влияют**.

**Рубрика** (она же на печатном листе `/#/print/N`):

| Критерий | Вес | Что смотрим |
|---|---|---|
| Функциональность | 50 % | Программы проходят испытания (видимые и скрытые) |
| Отладка | 20 % | Находит и исправляет ошибки по замечаниям заказчика и сообщениям Python |
| Стиль | 10 % | Понятные имена, PEP 8, без лишнего кода |
| Самостоятельность | 10 % | Подсказки только по необходимости, объясняет своё решение |
| Перенос в среду разработки | 10 % | Запускает скачанный `.py` в Thonny или IDLE |

≥ 85 % — «5», ≥ 70 % — «4», ≥ 50 % — «3».

**Звёзды задания** (балл системы 0–100): видимые тесты 40, скрытые 30, стиль 10, самостоятельность 10 (каждая подсказка снижает), точность уточнения ТЗ 10 (лишний вопрос заказчику обнуляет эту часть). 95+ — 5 ★, 80+ — 4 ★, 60+ — 3 ★. Задание принято при 3 ★.

**Диагностика.** Тест A (занятие 0, сразу после инструктажа — сначала объяснение, потом вопросы) и итоговый тест B (занятие 3) — одинаковые темы, разные примеры. Прирост «B − A» в процентных пунктах показывает рост группы. Это не оценка ученика.

## 8. Конец урока и отчёт

- **«Отчёт урока (CSV)»** — можно скачать во время урока и после завершения. Файл открывается в Excel. По строке на ученика:
  - этап и сколько этапов пройдено;
  - ответы на вопросы (верно / всего) и вызовы преподавателя;
  - по каждому заданию — звёзды, проверки, подсказки;
  - принято заданий, зачтено вами, проверено сервером;
  - диагностика A, диагностика B и прирост B − A.
- **«Завершить урок…» → «Да, завершить».** Вход по коду закрывается, ученики продолжают самостоятельно, их прогресс остаётся в браузерах.
- Журнал действий (входы, открытие этапов, зачёты, вызовы, опросы, комментарии) — `GET /api/teacher/sessions/{id}/log`.

## 9. Без сервера: дома, эксперты, школьники

- **«Самостоятельно»** (кнопка на титуле) — без сервера и кода урока. Этапы открываются по мере прохождения. Подходит для домашней работы и для экспертов.
- **«Знакомство: 2 занятия для школьников»** — только занятия 0–1, без входного теста. Для профориентации и дня открытых дверей. Вернуться к полному курсу можно в настройках, прогресс сохранится. В уроке с вашим кодом режим не действует: занятие задаёт пульт.
- **«Классика»** (настройки) — те же задания и проверки без сюжета, персонажей и премий, для тех, кому игровой слой мешает.
- Страница для экспертов — `/#/experts`.

## 10. Частые проблемы

| Проблема | Что делать |
|---|---|
| Ученики не открывают адрес | Тот ли адрес (из строки «Ученикам», не `localhost`)? Компьютеры в одной сети? Разрешите Python в брандмауэре Windows |
| «Урок с таким кодом не найден» | Урок завершён или код с ошибкой в цифрах. Буквы и раскладка не важны, цифры — важны |
| У ученика «нет связи» | Работа не теряется: прогресс сохраняется в браузере, связь восстановится сама. На пульте статус обновится в течение 20–45 секунд |
| Долго «Загрузка Python…» | Первая загрузка на слабом компьютере дольше обычной. Потом быстрее |
| Ученик потерял прогресс | Скорее всего, очищены данные браузера или открыт режим «инкогнито». Засчитайте сделанные задания вручную |
| Закрыли вкладку пульта | Урок продолжается. Откройте `…/#/teacher` снова — он откроется на текущем уроке |
| Пульт просит пароль снова | Вход действует 12 часов. Войдите ещё раз |
| Забыли пароль | `python -m bureau_server --reset-password` — новый пароль появится в окне |
| Сервер перезапустился | Уроки и ученики сохраняются, достаточно снова запустить `python -m bureau_server` |
| В Docker сервер пишет «адрес этого компьютера» | Внутри контейнера адрес компьютера неизвестен. Узнайте его (`ipconfig`) или запустите с `BUREAU_PUBLIC_URL=http://<адрес>:8000` |
| Ученик видит «Ждём экипаж» | Экипажи ещё не распределены: «Экипажи и гонка» → «Разбить на экипажи», или добавьте ученика из списка «Без экипажа». Ученик может нажать «Собрать программу одному» |
| Ученик просит «открыть дальше» | В режиме «Вместе» дальше ведёте вы. Если класс сильно разошёлся, переключите режим на «Свободно» |

## 11. Данные и приватность

- ФИО не собираются: только псевдоним, который ученик придумывает сам.
- Все данные хранятся на компьютере преподавателя (`server/data/bureau.db`) и в браузерах учеников. Внешних сервисов нет.
- Ответы на опросы анонимны. На проекторе нет псевдонимов.

## 12. Факты в игре

**Музей работает на урок.** Открытый экспонат показывает только название: текст таблички ученик читает кнопкой «Изучить». После принятого задания заказчик задаёт вопрос по экспонату (+10 премии, ответ один раз, только после изучения). В конце смены экипаж отвечает на музейный опрос, а сцена «Конец смены» завершается «Цитатой дня»: документальные слова Гагарина, Циолковского, Терешковой, Беляева с ФИО, годами, тем, чем человек занимался, и источником. Можно попросить класс вслух разобрать цитату на рефлексии.

Бюро «Космос», его сотрудники и заказчики придуманы. Реальные факты об отечественной космонавтике собраны с источниками в `docs/space-facts.md`, сюжетные тексты на проверку — в `docs/content-review.md` и `docs/review/`. Перед конкурсом или апробацией сверьте их.
